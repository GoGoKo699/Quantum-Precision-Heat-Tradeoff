## Public report

The self-contained explanatory report has five sections and sixteen subsections. It introduces prerequisites locally and contains no references, author block, or PDF author metadata. The reader-facing PDF lives in `learning/report/`; its editable source lives in `learning/source/`. The README report entry links only the PDF.

Use pdfLaTeX with TeX Live 2025 for the report source:

```bash
cd learning/source
pdflatex -interaction=nonstopmode -halt-on-error Quantum_Precision_Heat_Tradeoff_Report.tex
pdflatex -interaction=nonstopmode -halt-on-error Quantum_Precision_Heat_Tradeoff_Report.tex
cd ../..
python scripts/check_report.py --compiled
```

The explicit `--compiled` option requires the freshly built PDF and its corresponding log beside the source. Without that option, the checker inspects the committed public report. Missing build output must not be mistaken for a successful check of the older PDF. The read-only [report workflow](../.github/workflows/report.yml) retains the fresh PDF, log, and check record as artifacts. It does not overwrite the public PDF automatically.

The report's curve is generated by its inline PGFPlots expression. Its source does not depend on the separate Python generator below. Inspect the rendered pages after changing the report; source and compiler checks do not establish visual readability or scientific validity.

## Independent quantitative plot

The [Python generator](Graph/generate_plots.py) and [pinned requirements](Graph/requirements.txt) reproduce the vector crossover plot used in separately delivered source packages. They remain in this repository; the manuscript and its Overleaf ZIP do not. No manuscript is needed to run the generator.

```bash
python -m pip install -r verification/Graph/requirements.txt
python verification/Graph/generate_plots.py --output /path/to/Graph/crossover.pdf
```

The output is generated directly from the analytical formula, not a fitted curve or experimental dataset. The generator is regression-tested against `qph.core.crossover`. Its PDF is deterministic in the pinned environment. Do not hand-edit the PDF or treat the plotted limiting law as an exact finite-device optimum.

## Check a separately held package

A manuscript package is checked locally without copying it into the repository:

```bash
python scripts/check_overleaf_package.py /path/to/package.zip --output /path/to/check.json
```

The checker requires exactly `Quantum_Precision_Heat_Tradeoff_arXiv.tex` and `Graph/crossover.pdf`. It rejects extra files, external TeX or bibliography inputs, unresolved source references, duplicate archive members, and symlinks. It regenerates the plot from the current repository generator and requires byte-for-byte agreement. It does not execute the manuscript's TeX, publish the package, certify its scientific claims, or replace PDF review.

All schematic TikZ code and the bibliography belong inside the single manuscript TeX file. Python code and requirements stay in this repository, not in the delivered Overleaf ZIP. A check of one archive does not certify another archive with the same filename.
